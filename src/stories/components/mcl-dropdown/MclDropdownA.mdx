## Events

-`button-click`: (event: Event) - Event fired on dropdown button click.

-`item-click`: (event: Event, item: DropdownItem) - Event fired on dropdown item click.

## Keyboard accessibility

- `Tab` / `Shift+Tab`: move between the button and the items.
- `Enter` / `Space` on the button: open or close the list.
- `Arrow Down`: from the button (list open), focus the first item; on an item, focus the next item (no effect on the last item).
- `Arrow Up`: focus the previous item (no effect on the first item or the button).
- `Escape`: close the list and return focus to the button.
- Choosing an item closes the list and returns focus to the button.

The button exposes `aria-expanded` (whether the list is open) and `aria-controls` (the list's id) to screen readers.
