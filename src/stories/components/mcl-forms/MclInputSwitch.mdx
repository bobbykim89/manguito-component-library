# MCL Input Switch

Included in `@bobbykim/mcl-forms`

## Installation

```sh
npm i @bobbykim/mcl-forms
```

## Usage

`v-model` is a boolean. The control carries `role="switch"` for you.

```js
<script setup lang="ts">
import { MclInputSwitch } from '@bobbykim/mcl-forms'
import { ref } from 'vue'

const enabled = ref<boolean>(false)
</script>

<template>
  <mcl-input-switch v-model="enabled"></mcl-input-switch>
</template>
```

## Colors

The three color props name the parts they paint:

| Prop               | Paints                               |
| ------------------ | ------------------------------------ |
| `bg-color`         | the track when off                   |
| `checked-bg-color` | the track when on                    |
| `indicator-color`  | the sliding knob                     |
| `border-color`     | the track border, and the focus ring |

`rounded` is `true` by default, giving a full pill with a round knob. Set it
`false` for a soft rectangle.

## Field state

`id`, `name`, `invalid`, `required` and `disabled` are inherited from a
surrounding [MclFormGroup](?path=/docs/components-form-mclformgroup--docs)
when omitted. Leaving `invalid` unset is different from setting it `false`:
unset inherits, `false` overrides.

This control renders **no error region of its own**, so `invalid` alone only
sets `aria-invalid`; a message has to come from a group that owns the region.
