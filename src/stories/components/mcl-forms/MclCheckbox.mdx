# MCL Checkbox

Included in `@bobbykim/mcl-forms`

## Installation

```sh
npm i @bobbykim/mcl-forms
```

## Usage

`v-model` is a **boolean** — one model per checkbox.

```js
<script setup lang="ts">
import { MclCheckbox } from '@bobbykim/mcl-forms'
import { ref } from 'vue'

const isChecked = ref<boolean>(false)
</script>

<template>
  <mcl-checkbox id="my-checkbox" v-model="isChecked"></mcl-checkbox>
</template>
```

## Field state

`id`, `name`, `invalid`, `required` and `disabled` are all inherited from a
surrounding [MclFormGroup](?path=/docs/components-form-mclformgroup--docs)
when omitted. Leaving `invalid` unset is different from setting it `false`:
unset inherits, `false` overrides.

This control renders **no error region of its own**, so `invalid` alone only
sets `aria-invalid`. To show a message, let the group own the region with
`invalid-feedback`.

## Multiple checkboxes

Because the model is a boolean, a set is held as one boolean per value rather
than as a single array model. Setting `value` is still worth doing — it is
what each box submits in a native form post.
