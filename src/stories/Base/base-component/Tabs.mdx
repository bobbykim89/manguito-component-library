# Tabs component

Included in `@bobbykim/manguito-theme`

Unstyled components to build flexible tab components

## Usage

```js
<script setup lang="ts">
import {
  TabContainer,
  TabContent,
  Collapse,
} from '@bobbykim/manguito-theme'
</script>

<template>
  <TabContainer
    :body-class="['flex flex-col gap-sm py-lg md:py-2xl']"
    :btn-container-class="['border-b-2 border-b-warning']"
    :content-container-class="[
      'bg-light-4',
      'px-xs',
      'py-sm',
      'rounded-md',
      'overflow-hidden',
    ]"
  >
    <template #tab-button="{ tabAttrs }">
      <div class="flex justify-start">
        <button v-bind="tabAttrs(0)">Tab 0</button>
        <button v-bind="tabAttrs(1)">Tab 1</button>
        <button v-bind="tabAttrs(2)">Tab 2</button>
        <button v-bind="tabAttrs(3)">Tab 3</button>
      </div>
    </template>
    <template #tab-content>
      <TabContent :tab-number="0" id="tab-0">
        <div>
          <!-- tab 0 content -->
        </div>
      </TabContent>
      <TabContent :tab-number="1" id="tab-1">
        <div>
          <!-- tab 1 content -->
        </div>
      </TabContent>
      <TabContent :tab-number="2" id="tab-2">
        <div>
          <!-- tab 2 content -->
        </div>
      </TabContent>
      <TabContent :tab-number="3" id="tab-3">
        <div>
          <!-- tab 3 content -->
        </div>
      </TabContent>
    </template>
  </TabContainer>
</template>
```

## Accessibility

Bind `v-bind="tabAttrs(i)"` on each tab in the `tab-button` slot. It gives the tab:

- an id, `role="tab"`, `aria-selected`, and `aria-controls` pointing at the `TabContent` with the same `tabNumber`
- a roving `tabindex`, so the whole tab set is one Tab stop (the selected tab)
- click selection, and the keyboard: Arrow Left/Right move to the previous/next tab (wrapping), Home and End to the first and last

Each `TabContent` is then labelled by its tab, and has `tabindex="0"` so a panel with nothing focusable in it can still be reached with Tab. The container already wraps the slot in `role="tablist"`. A tab set that renders its own tabs without `tabAttrs` gets none of this, and its panels aren't labelled.

`TabAttrs` is exported as a type from `@bobbykim/manguito-theme`.

## SSR

The active tab is visible in the server HTML before its height is measured. The container has no `max-height` limit until the first height greater than 0 is measured. From then on `--container-hts` is always set, so `max-height` animates when you switch tabs.

### Props

#### TabContainer

- `bodyClass?` - string | string[]
- `btnContainerClass?` - string | string[]
- `contentContainerClass?` - string | string[]

#### TabContent

- `tabNumber` - number
- `id` - string
- `tabClass?` - string | string[]

### Slots

#### TabContainer

- `#tab-button(props: { update: (num: number) => void; activeTab: number; tabAttrs: (index: number) => TabAttrs })` - slot for tab buttons. Bind `tabAttrs(i)` on each tab (see Accessibility).
- `#tab-content` - slot for tab contents

#### TabContent

- `#default` - default slot

### Exposes

#### TabContainer

- `update` - (num: number) => void - update active tab index
