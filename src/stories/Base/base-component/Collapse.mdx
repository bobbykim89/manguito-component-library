# Collapse

Included in `@bobbykim/manguito-theme`

An animated collapsible panel with height and opacity transitions. The component owns its open/close state internally — control it through a template ref or through an `AccordionGroup` context.

```ts
import { AccordionGroup, Collapse } from '@bobbykim/manguito-theme'
```

---

## Usage

### Standalone

Hold a template ref and call `toggle()`, `open()`, or `close()` directly. For the button that opens it, `useCollapseTrigger` supplies `aria-expanded` (kept in sync with the panel) and `aria-controls` (pointing at the panel's `id`), so screen readers announce the button as expandable and whether it is open.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Collapse } from '@bobbykim/manguito-theme'
import { useCollapseTrigger } from '@bobbykim/manguito-theme/composable'

const collapseRef = ref<InstanceType<typeof Collapse>>()
// Destructure: templates only unwrap top-level refs.
const { attrs, toggle } = useCollapseTrigger(collapseRef, { id: 'panel-1' })
</script>

<template>
  <button v-bind="attrs" @click="toggle">Toggle</button>
  <Collapse ref="collapseRef" id="panel-1" custom-class="p-4">
    Collapsible content here.
  </Collapse>
</template>
```

Pass the same `id` to both. If the panel starts open, pass the same `visible` too (`useCollapseTrigger(collapseRef, { id: 'panel-1', visible: true })`): the template ref is empty on the server and until mount, so the trigger reads its starting state from there and the server HTML already has the right `aria-expanded`. In an `AccordionGroup`, give `visible` to one panel only, since only the first opens.

### Accordion with `AccordionGroup`

Wrap panels in `AccordionGroup` — only one panel can be open at a time. Each panel's `id` prop identifies it within the group.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { AccordionGroup, Collapse } from '@bobbykim/manguito-theme'

const panel1 = ref<InstanceType<typeof Collapse>>()
const panel2 = ref<InstanceType<typeof Collapse>>()
const panel3 = ref<InstanceType<typeof Collapse>>()
</script>

<template>
  <AccordionGroup>
    <div>
      <button @click="panel1?.toggle()">Panel 1</button>
      <Collapse ref="panel1" id="panel-1" custom-class="p-4"
        >Content 1</Collapse
      >
    </div>
    <div>
      <button @click="panel2?.toggle()">Panel 2</button>
      <Collapse ref="panel2" id="panel-2" custom-class="p-4"
        >Content 2</Collapse
      >
    </div>
    <div>
      <button @click="panel3?.toggle()">Panel 3</button>
      <Collapse ref="panel3" id="panel-3" custom-class="p-4"
        >Content 3</Collapse
      >
    </div>
  </AccordionGroup>
</template>
```

### Accordion with `v-for`

Store refs in an array when panels are generated from data.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { AccordionGroup, Collapse } from '@bobbykim/manguito-theme'

const items = [
  { id: 'panel-1', title: 'Section 1', content: 'Content for section 1.' },
  { id: 'panel-2', title: 'Section 2', content: 'Content for section 2.' },
  { id: 'panel-3', title: 'Section 3', content: 'Content for section 3.' },
]

const panelRefs = ref<InstanceType<typeof Collapse>[]>([])
</script>

<template>
  <AccordionGroup>
    <div v-for="(item, index) in items" :key="item.id">
      <button @click="panelRefs[index]?.toggle()">{{ item.title }}</button>
      <Collapse
        :ref="
          (el) => {
            if (el) panelRefs[index] = el as InstanceType<typeof Collapse>
          }
        "
        :id="item.id"
        custom-class="p-4"
      >
        {{ item.content }}
      </Collapse>
    </div>
  </AccordionGroup>
</template>
```

## SSR

Collapse content is always rendered in the server HTML. Closed panels are hidden with `display: none`, so the content is present for crawlers and hydration, and the open and close transition runs after hydration.

## API

### Props

| Prop           | Type                 | Default        | Description                                                                                                                               |
| -------------- | -------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `id`           | `string`             | auto-generated | Panel identifier used by `AccordionGroup` to track which panel is open. Also set as the element's HTML `id` attribute for ARIA wiring.    |
| `visible`      | `boolean`            | `false`        | Initial open state. Reactive — changing it after mount opens or closes the panel. In an `AccordionGroup`, the first `visible` panel wins. |
| `custom-class` | `string \| string[]` | `''`           | CSS class(es) applied to the inner content wrapper.                                                                                       |

### Slots

| Slot      | Description          |
| --------- | -------------------- |
| `default` | Collapsible content. |

### Exposed Methods

| Method   | Signature    | Description         |
| -------- | ------------ | ------------------- |
| `toggle` | `() => void` | Toggle open/closed. |
| `open`   | `() => void` | Open the panel.     |
| `close`  | `() => void` | Close the panel.    |

### Exposed State

| Property | Type      | Description                           |
| -------- | --------- | ------------------------------------- |
| `isOpen` | `boolean` | Whether the panel is open. Read-only. |

Inside an `AccordionGroup`, `visible` works the same way, but only one panel can be open: if several start `visible`, the first one opens. Setting `visible` to `true` later opens that panel and closes the open one.

### Events

| Event   | Payload              | Description                    |
| ------- | -------------------- | ------------------------------ |
| `open`  | `(visible: boolean)` | Emitted when the panel opens.  |
| `close` | `(visible: boolean)` | Emitted when the panel closes. |

### `useCollapseTrigger(collapseRef, options)`

Imported from `@bobbykim/manguito-theme/composable`.

| Option    | Type                        | Default | Description                                                                          |
| --------- | --------------------------- | ------- | ------------------------------------------------------------------------------------ |
| `id`      | `string`                    | —       | The `id` given to the `Collapse`. Becomes the trigger's `aria-controls`.             |
| `visible` | `MaybeRefOrGetter<boolean>` | `false` | The `visible` given to the `Collapse`. Used for `aria-expanded` until it is mounted. |

| Returns  | Type                                                                 | Description                        |
| -------- | -------------------------------------------------------------------- | ---------------------------------- |
| `attrs`  | `ComputedRef<{ 'aria-expanded': boolean; 'aria-controls': string }>` | Bind on the trigger with `v-bind`. |
| `isOpen` | `ComputedRef<boolean>`                                               | Whether the panel is open.         |
| `toggle` | `() => void`                                                         | Opens or closes the panel.         |
