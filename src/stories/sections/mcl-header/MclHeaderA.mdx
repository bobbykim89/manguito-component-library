## Accessibility

- `navLabel` (default `"Main"`) names the header's `<nav>` landmark. Give each landmark on a page a different name, for example when it also has a footer nav.
- `menuLabel` (default `"Menu"`) names the mobile menu button. The name stays the same; `aria-expanded` tells screen readers whether the menu is open.
- **Title.** It is plain text by default, not a heading, so the header doesn't add a heading to every page before the page's own `<h1>`. Set `titleLevel` (`'h1'`–`'h4'`) to render it as that heading; the look is the same either way (size comes from `titleSize`).
- **Logo.** The logo links to the same place as the title, so it is left out of the tab order and hidden from screen readers; the title link carries the name. Mouse clicks are unchanged.
- **Current page.** Set `current: true` on a menu item or a submenu child. Its link gets `aria-current="page"` and keeps its highlight on (underlined when `showHighlight` is off, and in the mobile submenus).
- **New tab.** Links with `target: '_blank'` (menu items and the title) include hidden "(opens in a new tab)" text.
- **Submenu buttons** (desktop dropdown, mobile collapse) have `aria-expanded` and `aria-controls`, and show a focus ring.

### Keyboard

- **Tab** moves through the title, the menu links and the submenu buttons.
- **Enter / Space** on a submenu button opens or closes it.
- **Desktop dropdown:** **Arrow Down** from its button, or from a link, moves to the next link; **Arrow Up** moves back. They stop at the first and last link and only act while the dropdown is open. **Escape** closes it and returns focus to its button.
- **After choosing a link:** in the desktop dropdown, focus returns to the dropdown's button; in the mobile menu, the menu closes and focus returns to the menu button.

## Slot

- `#content-right`: slot on the right side of the component
- `#mobile-bottom(props: { headerClose: () => void })`: slot at the bottom of collapse menu on mobile screen

## Events

- `toggle-drawer` - (event: Event, open: boolean) - event fired on drawer button click
- `title-click` - (event: Event, url: string, target: CtaTarget) - event fired on title block (title, logo) click
- `menu-click` - (event: Event, item: MenuItemType) - event fired on menu item click
- `collapse-click` - (event: Event, title: string, visible: boolean) - event fired on collapsable menu label click
